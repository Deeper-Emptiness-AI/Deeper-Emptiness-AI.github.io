# Healthya — 화면 디자인

고객 공유용 시안. 로컬에서 열어 보세요.

```bash
cd docs/renew-design && python3 -m http.server 8765
# → http://127.0.0.1:8765/index.html
```

| 파일 | 내용 |
|---|---|
| `index.html` | 표지 — 두 화면 방식 안내 |
| `D-daylight.html` | **일반 모드** (기본 화면) — 확정 |
| `Q-quiet.html` | **시니어 모드** (쉬운 화면 / 큰 글자) — 확정 |
| `assets/` | 시안용 예시 사진 (Wikimedia Commons) |
| `preview/` | 보드 캡처 이미지 |

일반 모드는 **실제로 움직입니다** — 첫 화면에서 하루가 24초에 한 바퀴 돌며 하늘이 밝아졌다 어두워지고, 해와 달이 뜨고 집니다. 정지 이미지로는 전달되지 않으니 브라우저로 여세요.

## 공통 계약 — 사진 하나로 통합

| 읽은 것 | 하는 일 |
|---|---|
| 음식 | 영양 분석 · 다음 끼니 제안 |
| 약통·처방전 | 약 정보 · 복약 검토 · 알림 편성 |
| 아픈 곳 | 증상 상담에 사진 첨부 + "언제부터" 1문항 |
| QR | 즉시 실행 (판정 화면 생략) |
| 그 밖의 사진 | AI 해설 — 무엇인가 / 알아둘 것 / 지금 나에게 |

두 화면 방식은 데이터·기능·알림·음성을 100% 공유하고 **표면만** 다릅니다. 설정에서 언제든 전환.
